# Политика безопасности

## Поддерживаемые версии

`singbox-exporter` пока не выпускается с тегами. Считайте последний коммит ветки по
умолчанию единственной поддерживаемой версией и пините его при деплое.

## Сообщение об уязвимости

Пожалуйста, **не** открывайте публичный issue для проблем безопасности. Сообщайте
о них приватно:

- Если для репозитория включён GitHub security advisory — используйте кнопку
  *Report a vulnerability* на вкладке *Security* репозитория.
- Иначе свяжитесь с мейнтейнером напрямую (e-mail или приватное сообщение),
  указав в теме письма слово `SECURITY`.

В отчёте укажите:

- затронутую версию (хэш коммита или тег),
- краткое описание проблемы,
- шаги воспроизведения и, по возможности, proof of concept,
- наблюдаемое влияние (что мог бы сделать атакующий).

Мы подтвердим получение отчёта в течение 3 рабочих дней и постараемся выпустить исправление
с координированным раскрытием. Пожалуйста, дайте нам время на фикс до публикации.

## Замечания о threat model

Экспортер рассчитан на запуск **на том же хосте**, что и sing-box, и чтение только
loopback-данных. Практические советы по ужесточению:

- биндите Clash API sing-box на `127.0.0.1` и задавайте `secret`; токен передавайте
  через `-token`,
- биндите порт экспортера на интерфейс, доступный только Prometheus,
- не выставляйте `/metrics` в недоверенные сети (label values экранируются, но весь
  этот деве-сайдликен вам на интернете не нужен).
